# PZ7 - Object-Oriented Programming in Java

Учебный проект, демонстрирующий принципы объектно-ориентированного программирования (ООП) в Java.

## 📋 О проекте

Проект содержит реализацию двух систем:
1. **Система сотрудников** - иерархия классов с наследованием
2. **Система фигур** - абстрактные классы и полиморфизм

## 🏗️ Архитектура проекта

### Система сотрудников (Employee Hierarchy)

Employee (базовый класс)
├── Manager (менеджер)
└── Developer (разработчик)

### Система фигур (Shape Hierarchy)
Shape (абстрактный класс)
├── Circle (круг)
└── Rectangle (прямоугольник)

## 📁 Структура проекта
src/
├── Main.java # Главный класс для тестирования
├── Employee.java # Базовый класс сотрудника
├── Manager.java # Класс менеджера
├── Developer.java # Класс разработчика
├── Shape.java # Абстрактный класс фигуры
├── Circle.java # Класс круга
└── Rectangle.java # Класс прямоугольника
